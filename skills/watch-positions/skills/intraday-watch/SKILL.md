# Intraday Watch

会话还在进行中,这里没有任何结论。本技能报告**现在**在动什么——相对大盘、相对各标的
自身常态离散度——并交给读者一份值得看的短名单;它不解释盘中异动,也不指导交易。

> 盘中**不做归因**:公告记录通常还没跟上价格,现在给出的原因就是「穿着引用外衣的猜测」。
> 用户问「为什么」时,说明披露记录在收盘后由 `close-recap` 核查,并递过去。

## 数据轨

优先 MCP 轨(工具清单里有 `hexin-stock__stock_highfreq_quotes` / `hexin-index__index_highfreq_quotes`
时);否则用包根规范的 akshare 兜底轨。两轨的关键差异:

- **涨跌幅口径不同**:iFinD 返回小数(`0.0512` = +0.05%,已验证过与日频工具同值同价);
  东财兜底轨返回百分数(`1.23` = +1.23%)。以所用来源的口径为准,不得乘错 100。
- MCP 盘中工具无历史(仅交易日日内);兜底轨 `quotes` 是东财延迟快照,**必须标注延迟与非实时**。
- 缺哪一个指标都如实说明:MCP 工具会静默丢弃服务不了的指标;兜底轨表格缺列同理。

## Workflow

### Step 1: 先确认真的是实时报价——从响应判断,不看时钟

**MCP `data_mode: "real_time"` 在非交易时段不报错**——它返回最后一个快照,附带快照时间。
所以报告任何数字之前:

1. 读返回行的 `time` 列(北京时间)。兜底轨读 `as_of` 并自行标注延迟。
2. 从会话上下文/环境取当前日期时间——环境时钟可能不是北京时间(UTC 容器差 8 小时,
   会让 16:01 的旧戳看起来像未来)。
3. 对比。时间戳不在当前交易时段内,**第一行就说明**,并给每个数字标注时点:

   > 盘中快照不可用 — 最新快照为 2026-08-07 16:01(北京时间),当前非交易时段。以下为该
   > 时点数据,非实时报价。

**绝不把滞后快照当实时报价,也绝不只凭环境时钟推断「已收盘」。** 09:30–11:30 或
13:00–15:00(北京)间几分钟内的时间戳才是活的;其余都是有时间戳的快照。

同时确定标的集合:`watchlists/` 下已存清单,或用户给的名单。存在多份清单且未指名时,问一次。

### Step 2: 拉快照

整个清单**一次调用**——MCP `symbols` 接受完整逗号串,不要逐只展开。兜底轨 `--codes` 同样
一次传全。值得要的指标:`最新价,涨跌幅,成交量,换手率`;按问题需要增减。

- 清单里没出现在返回表中的标的是**缺失**,不是平盘——本快照记 `源不可用` 并点名。停牌同。
- 盘中高低、开盘缺口、与昨收的对比不在本工具里:MCP 轨需另取
  `hexin-stock__get_stock_performance`(日频);兜底轨用 `hist`。工具没返回的盘中区间不得声称。

### Step 3: 同一刻的大盘

MCP:`hexin-index__index_highfreq_quotes` 取清单对应的基准(沪深300、上证指数、恒生指数),
同 `data_mode` 同刻调用。兜底轨:`index` 子命令,并说明两表时间戳可能不同步。

- **两个时间戳都取出来对比。** 10:42 的个股对 16:01 的指数不是相对涨跌。时点差异实质时,
  说明并**不计算**差值。
- 相对基准 = `标的涨跌幅 − 基准涨跌幅`,标 `[测算]`,附两个时间戳。

### Step 4: 哪些异动真的异常

原始 ±2% 名单在波动大的组合里全是噪音,在安静的组合里漏掉一切。先归一,与 `close-recap` 一致:

- MCP:`hexin-stock__get_risk_indicators` 取各标的 `波动率(年化)`,并从 `indicators_params`
  回读窗口(默认近 1 年)。兜底轨:用 `hist` 拉近一年日线自行计算年化波动率,标 `[测算]` 并写明窗口。
- 当「相对自身常态离散度足够大」时才标记,规则自选但必须陈述所用规则与所用波动率。
- 在自身常态范围内的异动,如实报告为常态,**不给任何叙事**。盘中,记录还没追上价格,
  没有可归因的东西——这种克制比收盘时更重要。

### Step 5: 输出

会话内短 Markdown。这是监控读数,不是文档——不主动出 PDF;用户明确要导出时:表格走
`xlsx-author`(`read {skills_dir}/watch-positions/skills/xlsx-author/SKILL.md` 后再动手),
每个硬编码单元格带 `Source: <数据商>, <数据时点>, <指标>` 批注并附 `来源` 工作表;
不带数据时点与来源的导出,两小时后与过期快照无法区分。

## Guardrails

- **本技能不出交易观点。** 不出现 买入/卖出/加仓/减仓/止损,不出现功能等同建议的
  「值得关注」。只报告动了什么、相对自身历史多不寻常;决定由组合经理做。
- **盘中不归因。** 不给盘中异动的成因——新闻、板块贝塔、形态都不行。指向收盘后的 `close-recap`。
- **每个数字带数据时间戳**,时间戳是供应商的、北京时间。`检索于` 与 数据时点 是两个字段,永不互替。
- absence 就是 absence:快照没返回的标的是 `源不可用` 并点名,永不省略、永不按最后已知价续用。
