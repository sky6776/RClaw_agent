# report.md 完整模板与写作规则

每次生成 `report.md` 时按此结构组织；没有的数据如实标注，不能为了填满模板而编造。

## 内容导航

- 一至二：技术面；商业模式、治理、资本配置与壁垒
- 三至四：历史财务、未来预测、三表、利润/EPS 桥与估值
- 五至七：交易结构、事件催化剂与逐项来源
- 八至十：综合判断、翻转条件与风险边界
