## 港股特有的驱动力

### 南向资金（北水）
- 内地资金通过港股通买卖港股的资金流
- 可能影响部分港股的边际定价，但影响强度取决于成交占比、流动性和同时发生的基本面事件
- 连续多日流向只能作为辅助证据，不能直接等同于后续涨跌或机构真实意图
- 关注指标：数据来源与口径、连续方向天数、占成交额比例、持股比例变化及股价是否同步确认

### ADR 隔夜效应
- ADR 可为次日港股开盘提供参考，但必须先按换股比例和汇率折算，并确认两地交易时段与公司事件
- ADR 溢折价不是确定预测；隔夜指数、汇率、流动性和港股开盘前新消息都可能改变方向
- 报告应给出折算口径和数据时间，使用“偏正面/偏负面参考”，不要写“必然高开/低开”

### 联系汇率制
- 港元盯住美元（7.75-7.85区间）
- 美元利率会影响港元金融条件，但港元利率还受总结余、期限结构和本地资金供求影响
- USD/HKD 接近 7.85 时应结合总结余和 HIBOR 观察流动性，不能直接写成股市必然利空

### 做空机制
- 香港一般禁止裸卖空；交易所仅允许符合规则的指定证券进行有担保卖空，并受价格、标记和申报等要求约束
- 做空报告是否影响股价取决于证据质量、公司回应、流动性和市场环境，不能预设方向或持续时间
- 卖空成交增加可能来自方向性做空、对冲或做市；必须结合卖空占成交比例、连续趋势和价格反应，不能直接等同“空头建仓”

## 事件分类及常见观察框架

| 事件类型 | 常见初始反应 | 重点验证 | 说明 |
|---------|-------------|---------|------|
| 财报超预期 | 偏正面 | 预期差、指引、现金流、估值 | 股价反应取决于结果相对市场预期，而非同比正增长本身 |
| 财报不及预期 | 偏负面 | 下修幅度、一次性项目、后续指引 | 区分经营恶化与会计/一次性因素 |
| 回购 | 偏正面 | 实际执行额、占市值比例、资金来源 | 公告额度不等于实际完成规模 |
| 分析师调整 | 不确定 | 机构、日期、盈利预测和目标价变化 | 不能只统计评级标签 |
| 行业监管 | 不确定 | 具体条款、适用范围、盈利传导 | 不把泛行业新闻机械套到个股 |
| 制裁/审查 | 偏负面且不确定 | 实体清单、业务暴露、缓释措施 | 只使用已确认公开信息 |
| 指数调整 | 可能产生被动流量 | 生效日、权重、预估流量与成交额 | 实际价格可能提前反映 |
| 股东减持/配售 | 偏负面 | 折价、规模、锁定期、资金用途 | 同时评估股本摊薄和流动性改善 |
| 管理层变动 | 不确定 | 人选、交接、治理和战略连续性 | 不预设利好或利空 |

## 港股/A 股估值口径纪律

- 估值方法和预测规范统一遵守 `analysis_guidelines.md`；这里不提供跨行业通用的 PE/PB/FCF Yield“便宜、合理、偏贵”阈值。
- A/H、ADR 或多币种上市比较前，先统一股份转换比例、股本口径、交易币种和汇率时点；溢折价本身不等于无风险套利空间。
- 比较港股 IFRS/HKFRS、A 股企业会计准则和美股 US GAAP 指标时，核对租赁、SBC、研发资本化、投资收益、少数股东权益和非经常性项目，不直接比较未调整倍数。
- 控股平台、地产和资产型公司使用 NAV 或分部估值时，单列净债务、交叉持股、税负和控股公司折价；折价率必须参考公司历史、治理和资产可变现性，不能套固定比例。
- 目标价必须来自可复核预测、估值假设和悲观/基准/乐观情景，不能从通用倍数区间反推。

| 形态 | 含义 | 后续方向 |
|------|------|---------|
| 多头排列(MA5>10>20>60) | 趋势偏强 | 结合斜率、位置和成交量确认 |
| 空头排列(MA5<10<20<60) | 趋势偏弱 | 结合跌幅、超卖和基本面确认 |
| MACD金叉 | 动能可能改善 | 需观察零轴位置和后续持续性 |
| MACD死叉 | 动能可能走弱 | 需观察零轴位置和后续持续性 |

| RSI<30 | 动量较弱/可能超卖 | 不能单独作为买入信号 |
| 放量突破压力位 | 突破证据增强 | 观察收盘确认与后续回踩 |
| 缩量上涨 | 参与度不足 | 结合趋势阶段判断 |
| 放量下跌 | 抛压增强 | 区分事件冲击与趋势破位 |
| 缩量下跌 | 成交低迷 | 不能直接推断底部 |

## A 股特有机制

### 北向资金（陆股通）

- 境外资金通过沪深港通买卖 A 股的资金流
- 可能影响部分 A 股的边际定价，但参与者构成多样，不能称为必然正确的“聪明钱”
- 连续多日流向仍需结合成交占比、价格、行业轮动和基本面事件验证
- 关注指标：来源与披露口径、连续方向天数、成交占比、持股变化及价格确认

与港股的南向资金对称：
- **南向资金**：内地资金买港股
- **北向资金**：境外资金买 A 股
- 分析 A 股时看北向，分析港股时看南向

### 涨跌停制度

- A 股涨跌幅限制随交易板块、上市阶段、证券状态和当时规则而异；分析时应根据标的和日期核对，不能只按固定百分比套用
- 港股没有与 A 股相同的日涨跌停制度，美股存在个股波动暂停等市场机制；不要简单写成“完全没有限制”

涨跌停对分析的影响：
- 封板反映当时价格约束和订单失衡，不能等同于下一交易日方向
- 连续封板会使可成交价格和流动性失真，应观察开板后的换手、成交量和事件进展

### 融资融券

- A 股的杠杆交易数据（两融余额/融资买入额）
- 融资余额持续增加可能代表杠杆需求上升，也可能只是价格上涨带来的名义规模变化
- 融资余额下降可能来自去杠杆、偿还或标的范围变化，需结合融资买入占比和价格判断
- 融券可用范围、规模和规则会变化；只使用分析时点可核实的数据，不预设其影响大小

### A 股特有的宏观因子

| 因子 | 怎么看 | 传导路径 |
|------|--------|---------|
| LPR（贷款市场报价利率） | 降 LPR → 利好消费/地产 | PBOC→LPR→企业融资成本→盈利预期 |
| 社融数据 | 超预期 → 实体经济在加杠杆 | 信贷投放→企业扩张→盈利增长 |
| PMI | >50扩张，<50收缩 | 制造业景气→工业股/原材料 |
| 国常会/政治局会议 | 关注政策表述变化 | 政策定调→板块轮动 |
| 印花税/IPO节奏 | 降印花税=重大利好 | 交易成本→市场情绪→成交量 |
