# 投资研究报告写作与布局

对 $ARGUMENTS 应用本写作与判断增强层，把底层投研结果整理成可用于决策的研究报告。保留原研究 skill 的数据纪律，同时强化具体生意机制、逆向思考、机会成本、行动阈值与克制的 Markdown 排版。

本 skill 不替代 `financial-data` 的数据规则、原始来源核查、估值工具或报告审计。长篇 AI Berkshire 输出默认称为“研究报告”；只有用户明确要求时才采用“投资备忘录”格式。

## 核心流程

1. **先给语境，证据之后再给完整决策。**
   - 首屏写明研究日期、价格、市值、核心估值指标和一句话论文。
   - 除非用户要求执行摘要，不在开头提前放完整买入/持有/卖出表。
   - 在论证生意质量、风险与估值后，再给投资者分层建议和价格区间。
   - 始终区分“好生意”和“当前价格下的好投资”。

2. **先画经营地图，再谈投资哲学。**
   - 前部说明收入结构、分部经济性、单位驱动因素和 3–5 年趋势。
   - 重资产公司的关键资产应逐项展示，尤其是能解释护城河的资产。
   - 解释定价机制、客户锁定、成本结构和再投资需求。

3. **用一句可记忆的话压缩生意本质。**
   - 说明谁付钱、为何付钱、什么稀缺、什么收入会重复。
   - 不单独使用“行业龙头”等泛化标签，必须继续解释优势机制。

4. **让护城河可以被证伪。**
   - 按品牌/定价权、转换成本、网络效应、规模、成本、监管、资源稀缺和技术逐项评分或列表。
   - 说明过去 5 年护城河变宽还是变窄。
   - 明确什么能摧毁护城河；答案可以不是竞争者，而是监管、周期、天气或买入价格。

5. **执行真正的逆向思考。**
   - 列出失败路径、概率、影响和可观察指标。
   - 用聪明的做空者或拒绝买入者真正会使用的语言写最强 bear case。
   - 明确最可能犯下的分析错误。

6. **通过资本配置评价管理层。**
   - 用并购、剥离、回购、分红、杠杆、再投资和战略转向记录替代笼统赞美。
   - 检查内部人持股、控制股东行为、薪酬、关联交易和股东回报政策。
   - 判断公司依赖某个人还是依赖一套系统。

7. **把行业趋势连接到价值捕获。**
   - 区分社会级长期趋势和可投资的公司级经济性。
   - 说明公司处于价值链哪个位置、谁获取利润池。
   - 明确真正驱动利润的是 TAM、价格、利用率还是资本强度。

8. **把估值转换为行动。**
   - 展示当前倍数、反向 DCF 直觉、情景估值、历史对比，以及适用时的可比公司。
   - 资本回报重要时将分红、回购等纳入预期回报。
   - 给出价格区间、加仓信号、减仓/卖出信号，以及改变论文的证据。

9. **以决策摘要收尾。**
   - 按生意质量、护城河、管理层、风险、趋势和估值汇总。
   - 分别给空仓投资者与现有持仓者建议。
   - 长篇报告的完整行动表放在结尾，而不是开头。
   - 最后区分 AI 分析置信度和真实投资确定性。

## 写作标准

- 用具体数字和机制代替形容词。
- 只有在降低认知负担时使用表格，例如资产、分部、失败路径、管理层决策、情景估值和行动区间。
- 使用一遍即可理解、一个月后仍可使用的投资者语言。
- 可以有可记忆的表达，但修辞不得跑在证据前面。
- 不以模糊的“观望”逃避判断；必须说明什么价格或事件会改变建议。

## 布局标准

- 标题默认使用 `公司名（ticker）研究报告`，除非用户要求，不添加“四大师综合”或“投资备忘录”。
- 公司类新报告使用 `reports/{公司名}/{公司名}-research-YYYYMMDD.md`；改写既有报告时沿用原路径，除非用户要求另存。行业或基金报告沿用底层研究 Skill 已确定的目录与文件名。
- 开头只放一个紧凑元信息块：研究日期、价格、市值、关键倍数和一句话论文。
- 大章节之间使用水平分隔线。
- 使用“第一步：核心数据总览”“第二步：生意本质分析”等短而具体的中文标题；除技术文档外避免 `2.3.1` 式密集编号。
- 大师式追问使用引用块，不用整段粗体。
- 把 GitHub Markdown 当作排版系统；除非用户明确要求非 GitHub 产物，不添加 HTML/CSS 字体样式。
- 克制使用粗体，只强调元信息标签、一句话结论、关键短语、总计/当前公司行、最新年度值、情景目标价、行动行和审计结论。
- 普通事实保持正常字重；不要把整张表或每个数字加粗。
- 增速和回报区间显式使用 `+` / `-` 号。
- 信息丰富或市场共识强时加入“AI 研究偏见自觉”检查。
- 报告末尾简要说明审计与工具使用；除非用户要求复现命令，不暴露命令行细节。
- 用户喜欢旧报告布局时，保留其阅读节奏，但只保留通过当前校验标准的数据。

## 默认报告结构

1. `AI 研究偏见自觉`
   - 信息丰富度评级、共识陷阱、偏见检查和 AI 研究局限。
2. `第一步：核心数据总览`
   - 分部收入、关键经营资产或单位、3–5 年财务趋势和跨来源校验。
3. `第二步：生意本质分析`
   - 一句话定义生意，展开收入、成本、客户、资产寿命、增长驱动和真正利润变量。
4. `第三步：护城河评估`
   - 逐项评分、证据和破坏/削弱护城河的条件。
5. `第四步：逆向思考与风险清单`
   - 严肃 bear case，列出失败路径、概率、影响和可观察预警指标。
6. `第五步：管理层评估`
   - 资本配置、治理、激励、分红/回购、杠杆和系统依赖性。
7. `第六步：行业与长期趋势`
   - 区分宏观趋势和可投资经济性，说明公司如何捕获价值。
8. `第七步：估值与安全边际`
   - 当前估值、反向 DCF、情景估值、可比公司和明确价格区间。
9. `第八步：最终决策与行动清单`
   - 汇总表、空仓者建议、持仓者建议、加仓/卖出触发条件。
10. `AI 分析置信度 vs 投资确定性`
    - 区分数据置信度和真实投资确定性。
11. `数据来源与审计记录`
    - 列出关键来源和简洁审计结果；默认不暴露命令行。

## 质量门槛

报告必须直接回答：

- 公司卖什么、卖给谁、为什么收入会重复？
- 真正驱动利润的 2–3 个变量是什么？
- 聪明人为什么可能拒绝买入？
- 当前价格已经计入什么预期？
- 乐观/中性/悲观情景下，含分红在内的合理回报是多少？
- 空仓投资者应该做什么？
- 现有持仓者应该做什么？
- 什么证据会推翻投资论文？

## 与其他 skill 配合

需要新鲜公司研究时，先执行相应数据/研究 skill 及其验证要求，再用本 skill 组织和改写输出。优先配合：

- `financial-data`：来源层级和跨来源校验。
- `investment-research`：巴菲特/芒格/段永平/李录框架。
- `management-deep-dive`：管理层质量是核心不确定性时使用。
- 报告审计动态工具：报告可发布或作为决策依据前执行对应入口。
