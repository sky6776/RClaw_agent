| 优先级 | 具体基金/候选 | 明确动作 | 当前占比/金额 | 建议区间/目标金额 | 问题类型 | 理由 | 前提/成本 |
|---:|---|---|---:|---:|---|---|---|
| 1 | {基金全称 [六位代码；份额类别；场内/场外]} | {渠道匹配的唯一动作 + 调整结果} | | | {产品问题/组合问题/投资者不匹配} | | |

涉及当前持仓时必须一只基金一行。禁止把指数、类别或基金公司简称当作持仓名称，禁止在一个单元格中合并多只持仓，也禁止只写“降低”“合并”“清理”“降低集中度”而不写交易动作和调整结果。每行只能保留该渠道实际适用的动作，不得在最终报告中写“赎回/卖出”等二选一动作。

- 错误：`合并A50 + 中证500 → 保留A500一只宽基`
- 正确：将 `{A50基金全称} [{六位代码}；{份额类别}；{已核验渠道}]`、`{中证500基金全称} [...]`、`{A500基金全称} [...]` 拆成三行；根据各行已核验渠道只填写“场外赎回”或“场内卖出”等唯一适用动作，并填写各自当前值与目标值。保持行同样写明“既不申购也不赎回”或“既不买入也不卖出”等渠道匹配动作。
- 尚未选定新增产品：具体基金/候选列写“非当前持仓（候选待筛选）”，明确新增类别、筛选条件和目标区间，不得虚构基金名称或代码；问题类型写“组合问题”。

分别标注：

- **产品问题**：基金本身是否应退出候选或更换；
- **组合问题**：基金合格但权重、重叠或共同因子不合理；
- **投资者不匹配**：与期限、回撤、流动性或币种要求冲突。
