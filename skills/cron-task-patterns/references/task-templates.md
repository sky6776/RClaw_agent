# 定时任务 message 模板库

以下为可直接复制、按需填空的 cron 任务 message 模板。所有「仅交易日」任务都用「daily + 消息内嵌交易日判断」实现。

---

## 1. A股个股分析（仅交易日）

```
今天是交易日吗？请先判断当前日期是否为A股交易日（排除周末和国家法定节假日）。
如果不是交易日，直接回复"今天非交易日，跳过分析"即可，不做任何分析。
如果是交易日，请使用 <技能名> 技能分析以下股票：<股票名称>(<代码>)。
分析结果通过QQ发送给用户。
```

cron_add 参数：
- `schedule_type`: daily
- `at_clock`: 09:00（或用户指定）
- `name`: 交易日每日<标的>分析

## 2. 多只股票批量分析（仅交易日）

```
今天是交易日吗？请先判断当前日期是否为A股交易日（排除周末和国家法定节假日）。
如果不是交易日，直接回复"今天非交易日，跳过分析"即可，不做任何分析。
如果是交易日，请使用 <技能名> 技能分别分析 <股票A>(<代码A>) 和 <股票B>(<代码B>)，将分析结果通过QQ发送给用户。
```

## 3. 黄金行情 + 持仓操作建议（仅交易日）

```
今天是交易日吗？请先判断当前日期是否为A股交易日（排除周末和国家法定节假日）。
如果不是交易日，直接回复"今天非交易日，跳过黄金分析"即可，不做任何分析。
如果是交易日，请使用 analyze-gold-market 技能分析当日黄金行情。
用户当前持仓信息：<持仓品种>持有约<金额>元，已<盈利/亏损><金额>元。
请结合当日行情和用户持仓盈亏，给出具体的操作建议（观望/加仓/减仓/止损等）。
分析结果通过QQ发送给用户。
```

## 4. 仅工作日（不含节假日，无需精准交易日历）

```
今天是工作日吗（周一至周五）？如果是周末，直接回复"周末跳过"。
否则，<任务指令>。
```

注：此变体只排周末，不识别法定节假日；若用户在意节假日，请用变体 1/2/3 的「A股交易日」判断。

## 5. 用户上下文嵌入要点

需要 Agent 根据用户实时状态给建议时，把状态写进 message：
- 股票：代码、持仓股数、成本价、当前盈亏。
- 黄金：持仓金额/克数、成本、当前盈亏。
- 基金：基金名称+代码、持仓金额、成本净值。

持仓信息会随时间变化；任务 message 是静态文本，必要时提醒用户更新（或每次触发时让 Agent 先查最新行情再算盈亏）。
