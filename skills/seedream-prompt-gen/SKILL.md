# Seedream 5.0 提示词生成技能

> **RClaw 使用说明：** 本 Skill 是纯知识型技能（无动态工具）。读取后由宿主
> Agent 按下述官方规则直接撰写/改写提示词，**完整输出最终 prompt**（可复制
> 使用），不要只给建议不给成品。生成 prompt 后如需出图，调用
> `skills/seedream-image/SKILL.md` 激活的 `skill__seedream_image__generate_image`。
> 撰写提示词不需要 API Key；只有实际生图才读 `skills/ark_key.toml`。

本技能依据火山引擎官方《Seedream 4.0-5.0 提示词指南》（官方覆盖 Seedream
5.0 lite / 4.5 / 4.0），把用户的粗糙想法转化为高质量提示词；规则对
Seedream 5.0 pro / flash 同样适用（其提示词理解能力更强）。

## 通用规则（五条，所有场景先过这关）

1. **用自然语言清晰描述画面**：简洁连贯地写明 **主体 + 行为 + 环境**，
   有美学要求再补 **风格、色彩、光影、构图**。
   - ✅ 一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈油画风格。
   - ❌ 一个女孩，撑伞，林荫街道，油画般的细腻笔触。（词组堆砌，不是自然语言）
2. **明确应用场景和用途**：有明确用途就写明图像类型。
   - ✅ 设计一个游戏公司的 logo，主体是一只在用游戏手柄打游戏的狗，logo 上写有公司名 "PITBULL"。
   - ❌ 一张抽象图片，狗拿着游戏手柄，狗狗上写 PITBULL。
3. **提升风格渲染效果**：有明确风格需求用**精准风格词**（莫奈油画、赛博朋克、
   扁平矢量插画）或提供参考图。
4. **提高文本渲染准确度**：要出现在画面里的**文字内容放双引号**。
   - ✅ 生成一张海报，标题为 "Seedream 5.0"
   - ❌ 生成一张海报，标题为 Seedream 5.0（不加引号易渲染错字）
5. **明确编辑目标和保持不变的部分**：编辑类指令简洁明确、指名对象、
   避免模糊代词；不希望被改动的内容要强调。
   - ✅ 让图中最高的那只熊猫穿上粉色的京剧服饰并戴上头饰，并保持动作不变。
   - ❌ 让它穿上粉色衣服。（「它」指代不明）

**硬约束**：中文提示词 ≤300 汉字、英文 ≤600 词；Seedream 5.0 理解力强，
**简洁精确优于堆砌华丽辞藻**——先满足规则 1，再逐步添加细节，不要为凑字数
重复修饰。

## 分场景模板

### 文生图（无参考图）

结构：`[用途/类型，] 主体 + 行为 + 环境 [ + 风格/色彩/光影/构图]`

细节丰富的画面靠**分层的空间描述**控制，例：

> 一个凌乱的办公桌桌面。桌面上有一台开着的笔记本电脑，屏幕显示绿色代码；
> 旁边一个马克杯，杯上写着 "Developer"，杯口冒出热气；一本摊开的书，页面是
> 维恩图，三个圆分别为灰色、蓝色和浅绿色；桌子角落是一小盆多肉植物。背景是
> 模糊的书架。阳光从右侧照射，在桌上形成光影。

知识/信息类图像（公式、图表、教学插图）：**用专业术语**确保知识点准确，
写清可视化形式与版式：

> 在黑板上画出下列二元一次方程组及其相应的解法步骤：5x + 2y = 26；2x - y = 5。

> 绘制一张信息图，展示通货膨胀的成因，每条成因独立呈现，并配有简洁图标。

### 图像编辑（单图输入）

四类操作的句式：

| 操作 | 句式 | 示例 |
| ---- | ---- | ---- |
| 增加 | 给图中<对象>增加<内容> | 给图中女生增加相同款式的银色耳线和项链。 |
| 删除 | 去掉<对象> | 去掉女生的帽子。 |
| 替换 | 把<对象>换成<新形象>，保持<不变项> | 把最大的面包人换成牛角包形象，保持动作和表情不变。 |
| 修改 | 让<对象>变成<新状态> | 让图中三个机器人变成透明水晶材质，颜色从左到右分别变成红黄绿。 |

### 视觉信号控制（涂鸦/线框/箭头）

画面复杂、文字难以指明对象时，指导用户**先在输入图上做标记**（涂鸦色块、
红框、箭头），提示词引用标记的颜色/位置：

> 将房间内红色涂抹位置放入电视，蓝色涂抹位置放入沙发，不改变其他布局，
> 确保放入物体和整张图的原木风格一致。

> 放大图中的标题至红框大小，并改成和萨克斯图案一样的颜色和字体风格。

### 参考图生图（保持形象/风格/款式）

提示词必须包含两部分，缺一不可：

1. **指明参考对象**：从参考图中提取并保留什么（人物形象 / 艺术风格 / 产品材质 / 款式）
2. **描述生成画面**：新画面的内容、场景、构图、风格细节

示例：

> 参考图中的人物形象，做一个动漫人物手办，放在桌上，后面放置一个印有角色
> 图像的生日礼物包装盒，盒子下面有一本书，将场景设置在室内，尽可能真实；
> 手办在图片的左边；整个图片的风格和原始图一样，大片摄影感。

> 参考图标的线性简约风格，设计9个不同场景下的应用 icon，包括：音乐、天气、
> 日历、相机、聊天、地图、闹钟、购物车、笔记本，保持一致的配色。

**草图 → 高保真**（平面图/线稿/手绘原型 → 效果图）：

- 提供清晰的原始图片；图中有文字说明则注明「遵循图中文字内容进行生成」
- 明确主体与要求：如「高保真 UI 界面」「现代简约风格客厅实景图」
- 明确与参考图一致的关键：如「房间布局、家具位置完全匹配例图」

> 根据这张平面图，生成 "现代简约风精装客厅 + 开放式餐厅"的实景图（房间布局、
> 家具位置完全匹配例图）。地中海风格配色，空间结构和方向始终与例图一致。

### 多图输入复合编辑（2-14 张参考图）

清楚指明**每张图的用途和操作**：

| 操作 | 模板 |
| ---- | ---- |
| 替换 | 将图一的主体替换为图二的主体。 |
| 组合 | 让图一人物穿上图二的服装。 |
| 迁移 | 参考图二的风格，对图一进行风格转换。 |

### 多图输出（组图）

用「一套」「一系列」「组图」或**具体数字**触发；逐张描述内容差异：

> 参考这个 LOGO，做一套户外运动品牌视觉设计，品牌名称为 "GREEN"，包括包装袋、
> 帽子、卡片、挂绳等。绿色视觉主色调，趣味、简约现代风格。

> 生成四张图，影视分镜，分别对应：宇航员在空间站维修飞船、突然遇到陨石带
> 袭击、宇航员紧急躲避、受伤后惊险逃回飞船。

> 生成周一到周日共七张手机壁纸图，自然景观，每张图对应标注日期。

组图 prompt 配合生图工具的 `max_images` 参数使用（参考图数 + 生成数 ≤ 15）。

## 交付格式

对每个请求输出：

1. **最终 prompt**：中文（或用户指定语言），可直接作为 `seedream-image` 的
   `--prompt` 使用，双引号包文字内容
2. **建议参数**（可选）：`size`（档位/宽高比建议）、是否组图（`max_images`）、
   是否参考图/联网搜索
3. **一句话说明**：套用了哪些规则（如「编辑类已指名对象并声明保持不变项」）

## 自检清单（输出前逐条核对）

- [ ] 是自然语言句段，不是关键词堆砌
- [ ] 主体 + 行为 + 环境齐全；风格/色彩/光影/构图按需补充
- [ ] 画面内要渲染的文字全部放在双引号中
- [ ] 编辑类：指名了编辑对象、写明了保持不变的部分、没有模糊代词
- [ ] 参考图类：同时写明「参考什么」和「生成什么」
- [ ] 多图类：每张图的用途/差异描述清楚，组图有数量词
- [ ] 中文 ≤300 汉字（英文 ≤600 词）；删掉了重复堆砌的修饰词
