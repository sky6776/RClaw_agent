# seedream-prompt-gen — Prompt 模板

Seedream 提示词撰写(纯知识型技能,无工具、不需要 API Key):按火山官方《Seedream 4.0-5.0
提示词指南》把用户的粗糙想法改写成完整可复制的提示词,覆盖文生图、图像编辑、视觉信号控制、
参考图生图、多图复合编辑、组图与草图转高保真。实际出图由 seedream-image 执行。

- 占位符用 `<>` 标出,替换后即可使用。
- 编号为全集连续编号(P155 起),与其他分册不重号。
- 输出必须是**完整最终 prompt**(可直接作为 generate_image 的提示词),不要只给建议不给成品;
  可附一句套用了哪些规则。
- 通用规则五条:自然语言描述(主体+行为+环境,再补风格/色彩/光影/构图)、写明用途、
  精准风格词、渲染文字放双引号、编辑类指名对象并声明保持项;中文 ≤300 汉字(英文 ≤600 词)。

整理日期:2026-09-23

---

### P155 文生图提示词生成
覆盖:通用规则 1-3(自然语言、用途、风格词);输出完整可复制 prompt

```text
帮我把这个想法写成 Seedream 提示词:<一个女孩撑伞走在林荫道上,想要油画的感觉>,
要求:自然语言写全主体、行为、环境和风格,画面里的文字用双引号,直接给我能用的成品。
```

### P156 编辑类提示词改写
覆盖:通用规则 5 + 编辑四类句式(增加/删除/替换/修改);指名对象、避免代词、声明保持项

```text
帮我把这条编辑需求改写成规范的 Seedream 编辑提示词:<把那顶帽子去掉,别的别动>,
要指名编辑对象(不说「它」),写明保持不变的部分。
```

### P157 参考图 / 组图 / 草图转高保真提示词
覆盖:参考图生图两部分结构(参考什么+生成什么)、组图数量词与逐张差异、草图转高保真的关键一致性声明

```text
我要用参考图做 <一套 9 个同风格的应用 icon>,帮我写好提示词:先写清参考图里要保留什么
(线性简约风格、配色),再写清 9 个 icon 分别是什么场景,最后给我建议的 max_images 参数。
```

```text
这是我家的 <装修平面图>,帮我写一条草图转高保真提示词:生成 <现代简约风精装客厅实景图>,
房间布局和家具位置要完全匹配例图。
```
