# cron-task-patterns — Prompt 模板

定时任务（cron）设计模式：调度器只支持 daily/weekly，用「消息内嵌条件」实现交易日过滤、
技能指定、标的与持仓上下文、输出渠道五段式 message；含 5 个可复制任务模板与任务增删纪律。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P116 起），与其他分册不重号。

整理日期：2026-09-05

---

### P116 交易日过滤的每日分析任务
覆盖：交易日过滤模板（daily + 消息内嵌"是否 A 股交易日，非交易日回复跳过" + 技能点名 + 标的 + 渠道五段式）

```text
帮我建一个定时任务：每个交易日早上 <9:00> 用 <glmv-stock-analyst> 分析一下
<海澜之家 600398>，要排除周末和国家法定节假日，
不是交易日就直接回复"今天非交易日，跳过分析"，结果发到 QQ。
```

### P117 多标的 + 持仓上下文任务
覆盖：多只股票批量模板 + 用户上下文嵌入（代码/持仓股数/成本价/盈亏写进 message）+ 黄金品种变体

```text
建一个每周一到周五早上 9 点的任务：帮我分析 <中国石油 601857> 和 <海澜之家 600398>，
我的持仓是 <中国石油 1000股 成本8.5>，给出操作建议，
只在工作日跑（周末直接回复"周末跳过"），结果发 QQ。
```

### P118 任务查看与删除
覆盖：任务管理（创建后 memory 记任务摘要；删除用 cron_remove 并同步清理 memory 条目）

```text
我现在有哪些定时任务？把 <任务名/编号> 那个删掉。
```
