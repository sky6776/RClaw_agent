# 宏观政策 read-macro — Prompt 模板

覆盖本包 4 个子技能：index-valuation / macro-dashboard / policy-tracker / asset-allocation，
以及产出技能 report-render（带图 PDF 长文）与 theses 状态文件存档回检。

- 占位符用 `<>` 标出，替换后即可使用。
- Prompt 不需要指定数据轨（MCP 双轨 / akshare 兜底脚本），技能按配置自动选择；
  若要专门测兜底轨，可在任意一条后追加：「假设 MCP 不可用，走兜底脚本」。
- 溯源纪律（`[披露]/[测算]/[推断]/[媒体]` 标签、`[n]` 引注、`覆盖范围与局限` 区块）是
  内置行为，不写进 prompt；验收时检查输出里是否带了即可。
- 编号沿用全集 P1–P26，与其他包分册不重号。跨包组合见
  `cross-package.md`（P25/P26 也用到本包功能）。

### P15 指数估值分位
覆盖：index-valuation（分位+回看窗口 / 编制信息 / 隐含 ROE / 盈利方向）

```text
<沪深300> 现在贵不贵？PE、PB 处在历史上什么位置，给我看 <10 年> 的分位，
写清楚窗口起始日；顺便算一下隐含 ROE，成分股盈利最近是在往上还是往下？
```

### P16 盈利 vs 估值拆分
覆盖：index-valuation Step 4（乘法拆分含交叉项）

```text
<2024年9月> 到现在 <沪深300> 涨了多少？里面多少是盈利贡献、多少是估值抬升？
把拆分方法和两个端点日期写明白。
```

### P17 板块估值
覆盖：index-valuation（板块估值三条路径）

```text
<申万食品饮料> 板块现在的估值水平怎么样？再给我它对应指数的 <5 年> 估值分位，
两条路用的哪个口径说清楚。
```

### P18 宏观仪表盘
覆盖：macro-dashboard（增长/通胀/货币/信用/外部五板块 / 每序列陈旧度与下次发布 / 板块间张力）

```text
现在宏观经济到底什么状态？增长、通胀、流动性、信用、外部五个方面各挑两三个关键指标，
每个都要标口径（同比/环比）、报告期、数据有多旧、下次什么时候更新；
哪些板块的数据在讲互相矛盾的故事也指出来。
```

### P19 货币-信用象限
覆盖：macro-dashboard Step 3.5（可复现判据 / 象限+置信度 / 可翻转信号）

```text
现在算宽货币还是紧货币？宽信用还是紧信用？
把判据写清楚（比如 DR007 对什么利率、社融存量同比看方向还是看水平），
落在哪个象限、置信度多少、什么信号出现会推翻结论。
```

### P20 政策与产业规划跟踪
覆盖：policy-tracker（规划原文检索 / 产业链节点映射 / 落地信号 / 规划目标与口号区分）

```text
帮我跟踪一下"<低空经济>"的产业政策：国家和重点地方各发了什么规划和文件，
产业链上中下游哪些环节被点到（哪些是文件点名的、哪些是你自己对应的要分开），
最近 <6 个月> 有没有落地动作（实施方案、专项资金、项目开工）？
规划量化目标和地方口号别混在一起说。
```

### P21 会议通稿措辞对比
覆盖：policy-tracker Step 4.5（同类会议措辞 diff / 状态文件持久化）

```text
对比最近这次<政治局会议>和上一次的通稿，哪些提法是新加的、哪些删了、哪些改写了？
措辞变化可能意味着什么？把这次的原文存下来，下次接着比。
```

### P22 大类资产配置观点
覆盖：asset-allocation（宏观主线 / 五条传导链 / 各资产观点+证伪路标 / 商品先检索 EDB / ERP 股债性价比）

```text
给我一版未来 <3-6 个月> 的大类资产观点，覆盖 A股、利率债、信用债、商品、汇率：
先说清楚现在宏观主线是什么、落在哪个货币-信用象限，五条传导链各指向哪；
每个资产的观点都要带"什么信号出现说明我看错了"的可验证路标；
商品先去搜搜有没有序列，别直接说没数据，供给端拿不到要说明；
再算一下现在股债性价比（ERP）在 5 年和 10 年什么分位，带上钝化提醒。
不要给配置比例和评级。
```

### P23 上期观点回检与存档
覆盖：asset-allocation Step 5.5（证伪路标兑现检查 / theses 状态文件）

```text
上次你给我的大类资产观点，当时留的证伪路标现在兑现了没有？
逐条对着最新数据检查，错的就大方承认错在哪，然后基于最新数据更新这期观点并存档，
下次继续回检。
```

### P24 长文配置报告带图
覆盖：asset-allocation Step 6 + report-render（4-7 张核心图）

```text
把最新这期大类资产观点写成一份 PDF 配置报告，要带图：
货币-信用象限近24个月的轨迹、宽基估值带、ERP 序列和分位、国债收益率曲线对比，
没数据画不了的资产类不要硬画空图。
```
