# glmv-doc-based-writing — Prompt 模板

基于给定文档（远程 URL 或本地 PDF，≤50 个/页）+ 写作要求，用 GLM-V 多模态模型写出
Markdown 文稿：论文/文章/报告/书评影评/新闻稿/简报/方案/发言稿等体裁。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P77 起），与其他分册不重号。

整理日期：2026-09-05

---

### P77 基于文档写作 + 保存
覆盖：write-from-documents（文档 + 完整写作要求 → Markdown 文稿；output 存 `.md`；会话内必须完整展示全文）

```text
基于这篇论文 <PDF路径或URL> 写一篇公众号文章：
偏技术风格、2000 字左右、先讲清楚它解决了什么问题。
生成后存成 md 文件，正文完整给我看。
```

### P78 自定义写作角色
覆盖：system_prompt 自定义系统提示词（如资深书评人）+ JSON 保存（output 存 `.json` + pretty）

```text
你是一位拥有 20 年经验的资深书评人。基于 <文档> 写一篇书评，
要有锋利的个人观点。结果存成 JSON。
```

# 功能点覆盖对照表

| 功能点 | 覆盖的 prompt |
|---|---|
| 基础写作（文档+要求 → Markdown） | P77 |
| 保存为 .md / .json | P77、P78 |
| 自定义 system_prompt 角色 | P78 |
| 本地非 PDF 文件转交 analyze_files | 在 P77 把输入换成 docx 即可触发 |
