# sd25-pe — Prompt 模板

Seedance 2.5 视频提示词优化(纯知识型技能,无工具、不需要 API Key,上游为火山官方
提示词指南推荐 skill v0.1.1):把粗糙想法、小说片段和可选的图/视频/音频参考,编译成
一条可直接提交给 Seedance 2.5 的干净 Prompt。生成执行由 seedance-video 承担。

- 占位符用 `<>` 标出,替换后即可使用。
- 编号为全集连续编号(P158 起),与其他分册不重号。
- 核心原则:意图优先(不改人物/道具/场景/因果)、模板优先(进对应模板重组,不做同义改写)、
  素材逐份负责(每份素材写明职责,未采用的逐个列入【未采用素材】)、参数分离
  (画幅/总时长/分辨率/声音开关不写进 Prompt)、默认只输出一个最佳版本。
- 素材引用 `@图片N/@视频N/@音频N` 原样保留;台词用 `{}`,音效用 `<>`,音乐用 `()`,
  字幕用 `【】`;镜头编号(`镜头45`)不得改写成机位角度。
- 默认只输出 Prompt 正文,不加 Markdown 标题、代码围栏或前后说明。

整理日期:2026-09-23

### P158 基础文生视频提示词编译
覆盖:纯文字输入 → 基础生成模板(主体/画面/镜头/声音四行结构)

```text
帮我把这个想法编译成 Seedance 2.5 可提交的提示词:<一位年轻陶艺师在清晨的工作室里拉坯,
最终做成一只窄口花瓶>,按主体动作、画面、镜头、声音的结构给我完整成品,参数不用写进去。
```

### P159 多素材职责映射
覆盖:【参考素材职责】+【主体与关系】+【事件脚本】+【保持一致】结构;未点名素材列【未采用素材】

```text
我有这些素材:<media/worker.png>(木工)、<media/chair.png>(旧木椅)、
<https://example.com/hands.mp4>(修椅动作),想生成一段 <修复旧木椅> 的视频。
帮我把每份素材的职责、主体映射和事件脚本写进提示词,用不到的部分列进【未采用素材】。
```

### P160 视频编辑 / 延长提示词
覆盖:编辑模板(唯一母版+编辑范围+保持内容+时间线继承)、延长模板(边界帧连续+单一实例)

```text
帮我把这条需求改写成可提交的视频编辑提示词:<把视频里经过长椅前方的红色自行车换成
一辆深灰色电动巡逻车,其他都不动>,要包含唯一编辑母版声明、编辑范围闭环和时间线继承。
```

```text
帮我把这条需求改写成向后延长的提示词:<视频结尾窗户打开后,镜头进入美术馆室内>,
要写清尾帧衔接、主体连续不分裂。
```

### P161 小说 / 长文本编译
覆盖:小说转可拍摄事件(保留人物关系、关键台词、因果与结局;阶段组织,不新增数字时间段)

```text
把这段小说改编成 <15> 秒的视频提示词:<粘贴小说片段>,保持人物关系、关键台词和
结局状态,按阶段组织事件,不要虚构原文里没有的情节。
```
