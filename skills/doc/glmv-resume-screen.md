# glmv-resume-screen — Prompt 模板

用 GLM-V 按用户自定义筛选标准批量读取并评估简历（≤50 份：远程 URL 支持 pdf/docx/txt，
本地仅 PDF ≤50 页），输出含 ✅/❌/⚠️ 与符合程度的 Markdown 表格。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P91 起），与其他分册不重号。
- 简历附件本身不构成筛选授权：无目标/无标准时 agent 会先询问。

整理日期：2026-09-05

---

### P91 批量简历筛选
覆盖：screen_resumes（files + 自定义 criteria + 自定义 system_prompt + 保存 .md/.json；输出表格列：序号/姓名/是否符合/符合程度/原因分析）

```text
这批简历 <文件列表或目录> 按这些标准筛一遍：
<3年以上 Python 开发经验、有大型项目管理经验、本科以上学历>。
你按资深技术面试官的视角评，重点看项目深度。
输出符合与否的表格，存成 md 文件发我。
```
