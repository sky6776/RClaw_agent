# glm5v-multimodal — Prompt 模板

GLM-5V-Turbo 通用多模态分析：视觉问答、多图对比、图表解读、文档问答、自定义结构化提取。
三个互斥媒体入口（图片 / 视频 / 文件），一次只用一种。仅当任务不匹配任何更专用技能时使用。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P99 起），与其他分册不重号。
- 本地图片 ≤8 张（5MB/6000px）；本地视频 ffmpeg 抽帧、不含音频、单次 1 个；文档 ≤8 个
  （PDF/DOC/PPT/XLS/CSV/TXT/MD/HTML）；不支持独立音频。

整理日期：2026-09-05

---

### P99 视觉问答与多图对比
覆盖：analyze_images（本地路径或 URL 数组、自定义 prompt、按序"图1/图2"映射回答）

```text
对比一下这两张图 <图1路径> 和 <图2路径> 有什么区别，
逐项列出来。
```

### P100 图表解读 + 结构化提取
覆盖：自定义 prompt 指定输出格式（如 JSON 字段清单）+ output 参数保存长结果

```text
解读这张图表 <图片路径>：把每个数据点提取出来，
按 <JSON：字段名、数值、单位、同比> 的结构输出，存成文件。
```

### P101 视频内容分析
覆盖：analyze_videos（远程 URL 原生视频；本地视频 ffmpeg 均匀抽帧近似分析——只覆盖画面不含音频，本地单次 1 个）

```text
分析这个视频里发生了什么：<视频URL 或 本地视频路径>。
```

### P102 文档问答
覆盖：analyze_files（本地 Office/PDF/文本 或远程 URL；本地文件先经智谱解析接口提取内容）

```text
这个文档 <PPTX/PDF 路径> 里关于 <问题主题> 的内容是什么？帮我总结一下。
```

### P103 长提示词文件与干跑校验
覆盖：prompt_file（长提示词从 UTF-8 文件读入，可与 prompt 叠加）+ dry_run（只校验输入不调 API）

```text
按 <提示词文件路径> 里写的要求分析这批图片 <图片列表>，
先干跑校验一遍输入没问题再真正调用。
```
