# evaluate-fund — Prompt 模板

国内公募基金与持仓的系统评估：单基金体检、多基金比较、持仓穿透分析、底层股票研究、
份额选择、净值序列计算、持仓截图识图，产出可经 RClaw 外部 channel 发送的 Markdown + 自包含 HTML 报告。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P36 起），与其他分册不重号。

整理日期：2026-09-05

---

### P36 单基金体检
覆盖：单基金体检（产品身份核验 → ≥3 年总回报/基准/回撤/经理任期/持仓 → 策略兑现/风险/费用/红旗 → 评分与结论）

```text
系统评估一下 <基金名称/六位代码>：业绩和基准比怎么样、最大回撤多少、
现任经理任了多久、持仓风格有没有漂移、费用高不高，有没有红旗？
最后给我适合/有条件适合/暂不适合的结论。
```

### P37 多基金比较
覆盖：多基金比较（统一份额/币种/区间/总回报/基准，2–8 只并行收集，暴露差异、扣费后效率、底层重复、相关性）

```text
把 <基金A>、<基金B>、<基金C> 放在一起比：统一用 <份额类别>、近 <3年> 区间，
比收益、回撤、费用效率、重仓股重合度和相关性，哪只更适合 <我的持有目标>？
```

### P38 当前持仓穿透分析
覆盖：当前持仓分析（portfolio.json → analyze_portfolio → 资产类别/行业/板块/地区/币种/风格/风险标签穿透、集中度、底层重叠 → 对照 targets/limits 给调整方向+优先级）

```text
这是我的基金持仓：<基金1 金额>、<基金2 金额>、<基金3 金额>。
帮我穿透分析：行业、风格、地区、币种暴露分别是多少，底层股票重合度高不高，
经理/公司/指数集中度有没有超标？我的目标是最大回撤不超过 <x>%，
对照这个目标给我调整方向和建议区间，标好优先级。
```

### P39 底层股票研究
覆盖：股票持仓研究（前十大、占净值 5%+、多基金重复持有、穿透后占组合 3%+、有红旗的股票）

```text
我持仓穿透出来的重合股票里，哪些值得单独研究一下？
把被多只基金重复持有、穿透权重最高的几只讲讲基本面。
```

### P40 份额/交易方式选择
覆盖：份额选择（A/C/E/I、累计/分配、场内/场外的实际全部费用成本比较）

```text
<基金名称> 的 A 类和 C 类我该怎么选？我预计持有 <1年>，
把申购费、销售服务费、赎回费全算进去告诉我哪个便宜。
```

### P41 净值 CSV 计算
覆盖：净值序列计算（calculate_fund_metrics / compare_funds：年化、波动、回撤、夏普、相关性、相对基准）

```text
我有个基金净值 CSV（路径 <csv 路径>），帮我算年化收益、最大回撤、夏普比率，
多只基金的话算一下两两相关性，能对基准的话和 <基准> 比一下超额。
结果存成文件。
```

### P42 持仓截图识图 + 报告投递
覆盖：GLM-5V 识图（extract_evidence：portfolio-screenshot / fund-document / fund-chart 三种模式）
+ 报告生成投递（render_report：自包含 HTML + MD，外部 channel 媒体标记）

```text
这是我持仓 App 的截图，帮我识别出来都有哪些基金、各多少钱。
识别完连同 <基金代码> 一起做穿透分析，最后生成一份能发到 QQ 的 HTML 报告。
```
