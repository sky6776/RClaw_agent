# glmocr-table — Prompt 模板

GLM-OCR 表格专用变体：从图片/PDF 提取表格（合并单元格、嵌套表、多行表头、多页批量）转
干净 Markdown 表格。参数与 glmocr 一致。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P97 起），与其他分册不重号。

整理日期：2026-09-05

---

### P97 表格提取
覆盖：extract_tables（复杂表格/财务报表/发票 → Markdown 表格；多页 PDF 批量提取）

```text
提取 <这张财报截图 / PDF路径> 里的表格，转成 Markdown，
合并单元格要还原对，多页的话每页的表都要。
```
