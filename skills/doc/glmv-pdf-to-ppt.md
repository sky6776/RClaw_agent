# glmv-pdf-to-ppt — Prompt 模板

把 PDF（论文/报告/文档）转成精修的 `.pptx` 演示文稿：渲染页面 → GLM-V 逐页分析 →
规划 8–15 页大纲 → grounding 定位裁剪图表 → 复核 → 生成 PPTX → 附 outline.json 与 summary.md。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P83 起），与其他分册不重号。
- 输入支持本地 PDF 或 HTTP(S) URL；>100MB 或 >200 页会被拒绝。

整理日期：2026-09-05

---

### P83 标准 PDF 转 PPT
覆盖：完整七阶段流程（渲染 dpi 120 → 每批 ≤8 页逐页分析 → 8–15 页大纲 → 裁剪目标 grounding+复核 → 版式选择 → PPTX 生成 → summary.md）

```text
把这篇论文 <PDF路径或URL> 做成 PPT。
```

### P84 指定语言/风格/页数
覆盖：语言匹配（中文 PDF→中文幻灯片）、风格指定或按领域推断、页数与布局偏好

```text
根据 <PDF> 做一份 <中文> 幻灯片，<12> 页左右，
风格要 <干净现代的学术风>，图表多的页用大图版式。
```
