# glm-quota-query — Prompt 模板

查询智谱 GLM Coding Plan 编码套餐实时额度：5 小时/每周 Token 窗口已用百分比与重置倒计时、
MCP 工具月度配额（联网搜索/网页读取/开源仓库）、套餐档位，可选 24 小时模型 Token 用量。

- 编号为全集连续编号（P108 起），与其他分册不重号。
- API Key 复用 glmv-stock-analyst 的 config.toml，只由脚本内部读取，不打印不外传。

整理日期：2026-09-05

---

### P108 查窗口额度
覆盖：quota 默认查询（5 小时 Token 窗口、每周 Token 窗口的已用百分比 + 重置倒计时）

```text
查一下 GLM 额度：5 小时窗口和每周窗口还剩多少，什么时候刷新？
```

### P109 MCP 配额与套餐档位
覆盖：MCP 工具月度配额（联网搜索/网页读取/开源仓库的已用/剩余次数）+ 套餐档位（lite/pro/max）

```text
MCP 工具的月度配额用了多少？联网搜索、网页读取、开源仓库各剩几次？
我現在是什么套餐档位？
```

### P110 24 小时模型用量
覆盖：--model-usage 追加查询（24 小时内各模型 Token 用量统计；端点回空体时如实标"暂无数据"）

```text
顺便看看最近 24 小时各模型的 token 用量。
```
