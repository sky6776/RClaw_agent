# ai-berkshire — Prompt 模板

价值投资研究包（巴菲特/芒格/段永平/李录框架）：公司深度研究、四大师团队交叉质询、财报精读、
行业漏斗与产业链、管理层纵深、论文追踪、组合审视、公众号文章等 21 个子技能。
报告写入包内 `reports/{公司名}/`，带审计准出流程（lint→抽样→双源→preflight→verdict）。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P54 起），与其他分册不重号。
- 不指定子技能时 agent 会按目标自动路由；明确点名（如"做一次四大师团队研究"）则按指定执行。
- financial-data 是被所有研究类技能引用的数据规范（双源交叉验证、误差分级），无独立触发入口。

整理日期：2026-09-05

---

### P54 交易日每日增量分析
覆盖：daily-stock-analysis（复用已准出深度报告作基线、只增量更新、交易日历确认、重大事件升级完整研究）

```text
交易日了，帮我增量更新一下 <腾讯> 今天的 daily 分析：
只看新行情、新公告、新事件，别重写整份深度报告。
```

### P55 单 Agent 综合研究
覆盖：investment-research（统一上下文七模块：生意本质→护城河→逆向风险→管理层→行业趋势→估值三情景→决策备忘录，报告带信息丰富度评级）

```text
对 <比亚迪> 做一次系统化的深度投资研究：
生意本质、护城河、逆向风险、管理层、行业趋势、估值三情景一个都不能少，
最后给我明确的决策备忘录。
```

### P56 四大师团队研究与交叉质询
覆盖：investment-team（4 个独立子 agent 并行研究 + 多轮交叉质询 + team-lead 汇总；多公司逐家串行）

```text
组织四大师团队研究 <宁德时代>：四个独立视角分别研究，
互相质询至少一轮，最后汇总成带 Bull vs Bear 和分层建议的最终报告。
```

### P57 财报精读
覆盖：earnings-review（一手财报原文精读：管理层语气与承诺追踪、附注隐藏信息、电话会 Q&A、明确超/符/低预期结论）

```text
精读一下 <美团> 最新一期财报：管理层承诺兑现得怎么样、
附注里藏了什么、电话会问了什么，结论必须明确说超预期还是低于预期。
```

### P58 财报团队精读 + 公众号文章
覆盖：earnings-team（四大师并行精读 → 合成研究报告 → 编辑改写公众号文章 → 读者评审把关 → 定稿 7 件套）

```text
用团队模式精读 <拼多多> <2025Q4> 财报，
四个大师各自精读后交叉质询，最后产出一篇可以直接发的公众号文章。
```

### P59 行业漏斗筛选
覆盖：industry-funnel（全市场 30-60 家 → 硬指标粗筛 ≤10 家 → 精细分析 → 四大师深析终选 3 家，每层留淘汰理由）

```text
对 <创新药> 行业做一次漏斗式筛选：从全市场扫到终选 3 家，
每一层为什么淘汰谁都要写清楚。
```

### P60 行业产业链全景研究
覆盖：industry-research（投资逻辑链验证 → 产业链全景图 → 全球上市公司扫描 → 头部公司四大师分析 → 核心/卫星/期权/ETF 四层配置）

```text
对 <AI 算力> 做一次产业链全景投资研究：
把上中下游每个环节验证清楚，扫描全球上市公司，
头部公司做四大师分析，最后给行业配置建议。
```

### P61 买入前 Checklist
覆盖：investment-checklist（巴菲特六关：能力圈/好生意/护城河/管理层/安全边际/决策纪律 + 镜子测试 + 快速否决清单；支持多公司）

```text
帮我把 <腾讯>, <茅台>, <英伟达> 都过一遍买入前 Checklist：
六关逐关打分，镜子测试过不过，有没有触发快速否决项。
```

### P62 报告写作增强/改写
覆盖：investment-memo-craft（研究报告的写作、改写、修订、布局增强：可证伪护城河、逆向分析、估值到行动映射）

```text
把 <这份既有研究报告路径> 改写增强一下：
护城河要写成可证伪的，估值要落到行动清单，
排版克制一点，别用 HTML。
```

### P63 管理层纵深研究
覆盖：management-deep-dive（诚信/能力/资本配置/治理四维 + 侧面验证 + CEO 离开情景 + 加权评分）

```text
深度研究一下 <王兴 美团> 的管理层：
诚信度、能力、资本配置、治理结构都要评，
侧面验证一下员工和客户怎么评价他，CEO 离开公司会怎样？
```

### P64 股价异动快速归因
覆盖：news-pulse（4 个并行 Agent 侦察公司事件/监管/对手/情绪 → 时间线 + 主因判断 + 是否触发论文重审；时间窗默认 14 天）

```text
<公司名> 最近 <跌了 12%/3 天>，帮我快速归因：
四个维度并行侦察，给我事件时间线和主因判断，
看看要不要触发投资论文重审。
```

### P65 投资组合审视
覆盖：portfolio-review（单仓位体检三问 + 集中度/相关性/机会成本/压力测试 + 调仓建议 + 更新 portfolio-latest.md）

```text
审视一下我的组合：<腾讯30%, 美团20%, ...>。
每个仓位做个体检，组合层面看看集中度、相关性和机会成本，
给调仓建议并更新组合档案。
```

### P66 未上市公司研究
覆盖：private-company-research（6 Agent 并行拼图、信息稀缺下还原真实价值、三档估值与安全边际、信息盲区地图）

```text
帮我研究未上市的 <SpaceX>：
六个角色并行拼图，数据冲突要仲裁，
给出保守/合理/乐观三档估值和信息盲区地图。
```

### P67 去劣筛选
覆盖：quality-screen（7 条硬指标 + 3 条豁免规则；支持个股列表/行业/指数/主题四种模式）

```text
把 <中国啤酒行业> 的公司做一遍去劣筛选：
7 条硬指标逐条过，能豁免的说明豁免理由，
通过的、排除的、边界争议的分开展示。
```

### P68 投资论文建立与追踪
覆盖：thesis-tracker 两种模式（建立：5 句论文 + 3-7 条可验证假设 + 红线 + 估值锚点；检查：逐条假设🟢🟡🔴⚫ + 健康度评分）

```text
帮我给 <腾讯> 建立一份结构化投资论文存档：核心论文 5 句话、
可验证的假设清单、红线清单、估值锚点。
```
```text
对 <腾讯> 做一次季度论文检查：逐条假设核对最新数据，
红线有没有触发，论文健康度还剩多少分？
```

### P69 论文漂移检测
覆盖：thesis-drift（对比新旧报告，只认证据变化不认措辞变化，Improved/Unchanged/Weakened 三值判定）

```text
检测一下 <腾讯> 的论文漂移：把新旧两份报告对比，
分清哪些是事实变化、哪些只是价格变化、哪些只是措辞变化。
```

### P70 公众号文章
覆盖：wechat-article（研究 → 作者 → 编辑 → 读者三 Agent 串行协作，产出可直接发布文章；可指定读者/深度/长度/风格）

```text
以 <科普> 深度写一篇关于 <主题> 的公众号文章，
目标读者是 <普通人>，<4000> 字左右，对话式风格，要能直接发布。
```

### P71 供应链瓶颈猎手
覆盖：bottleneck-hunter（超级趋势物理分层拆解 Layer 0-4、S/A/B 级瓶颈判定、标的估值红黄绿灯、动态瓶颈地图）

```text
扫描一下 <能源转型> 这个趋势的供应链瓶颈：
物理分层拆解，识别 S/A/B 级瓶颈，筛出标的并做估值检查，
更新瓶颈地图和观察清单。
```

### P72 《看懂 XX》深度公司系列
覆盖：deep-company-series（3-8 篇公众号级长文系列：5 年年报+研报打底 → 逐篇写作 → 跨篇一致性扫描 → 隐私扫描；篇数先确认）

```text
帮我写一个《看懂 <小米>》深度系列：
按公司复杂度定篇数，先跟我确认篇数和每篇论点再动笔。
```

### P73 段永平问答
覆盖：dyp-ask（以段永平第一人称回答任意问题，按投资/商业/人生/公司/宏观路由思维框架；纯会话、无文件）

```text
用段永平的视角回答我：<我的问题>。
```
