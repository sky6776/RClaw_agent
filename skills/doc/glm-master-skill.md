# glm-master-skill — Prompt 模板

GLM 官方技能导航与运行规范：在 16 类 GLM 能力（OCR/生图/多模态理解/定位/简历筛选/写作/
PDF 转换/应用与网站生成/股票分析等）之间路由到正确的本地 skill，并定义外部 channel 的
附件意图门禁与统一媒体发布机制（publish_media）。本包只路由、不直接调 API。

- 编号为全集连续编号（P106 起），与其他分册不重号。
- 本包的"功能"主要是路由与门禁行为，prompt 模板用于验收这两类行为。

整理日期：2026-09-05

---

### P106 附件意图门禁
覆盖：附件门禁（只发附件/媒体 URL 不说明目标 → 不读不调 API，按媒体类型给 2–5 个选项询问；
目标明确或前文已交代 → 直接执行不重复确认）

```text
（先只发一个视频附件，不加任何说明）看看这个
```
> 预期行为：agent 列出该视频可做的处理选项（摘要/时间线/画面文字识别/目标定位跟踪/prompt 生成）让你选，而不是自作主张。

```text
我下一条发你一个视频，帮我做个内容摘要。
（随后发出视频）
```
> 预期行为：目标已明确，直接执行摘要，不再反问。

### P107 能力路由与媒体发送
覆盖：路由表（需求 → 正确 skill：描述→caption、OCR→glmocr 家族、定位→grounding、生图→glm-image-gen、PDF→PPT/网页、PRD→应用、股票→stock-analyst……专用优先）+ publish_media（文件发外部 channel，media_type: auto/file/image/video/voice，可指定收件名与说明）

```text
<发一张表格截图> 帮我把这里面的数据提取出来
```
> 预期路由：表格 OCR → glmocr-table（不是通用 glm5v）。

```text
把 <文件路径> 发给我 / 发到 QQ。
```
> 预期行为：经 publish_media 发布，通道未启用时只给本地路径、不谎称已发送。
