# 基金筛选 pick-funds — Prompt 模板

覆盖本包 5 个子技能：fund-screen / fund-profile / fund-watch / holdings-style / manager-profile，
以及两个产出技能 report-render（PDF/DOCX）、xlsx-author（Excel）。

- 占位符用 `<>` 标出，替换后即可使用。
- Prompt 不需要指定数据轨（MCP 双轨 / akshare 兜底脚本），技能按配置自动选择；
  若要专门测兜底轨，可在任意一条后追加：「假设 MCP 不可用，走兜底脚本」。
- 溯源纪律（`[披露]/[测算]/[推断]/[媒体]` 标签、`[n]` 引注、`覆盖范围与局限` 区块）是
  内置行为，不写进 prompt；验收时检查输出里是否带了即可。
- 编号沿用全集 P1–P26，与其他包分册不重号。跨包组合见
  `cross-package.md`（P25 也用到本包功能）。

### P8 多条件基金筛选
覆盖：fund-screen（类型/业绩/规模/费率/经理任职多条件 / 年化口径复算 / 份额去重 / 场内外范围）

```text
帮我筛基金：场内外都要，股票型和偏股混合型，近3年年化收益超过 <15>%，
规模 <50> 亿以上，管理费低于 <1.5>%，现任经理任职满 <3> 年，按近3年收益排序。
注意"近3年年化"如果引擎给的不是几何年化，用累计收益帮我重算再卡门槛；
同一个基金 A/C 份额只留一行；筛完告诉我下一步该看什么。
```

### P9 筛选结果导出
覆盖：fund-screen Step 4（Class B 工作簿 / PDF 筛选点评）

```text
筛选结果导出成 Excel，我要继续加工；再出一份 PDF 版的筛选点评，转发用。
```

### P10 单基金画像
覆盖：fund-profile（业绩与风险 / 基准对比 / 经理任期切分 / 规模与持有人 / 资产配置与费率三档 / 重仓股 / 结构性风险）

```text
深度分析一下 <基金代码/简称>：业绩怎么样、和基准比、和同类比；
现任经理是中途接手的，把他上任以来单独切一段算；
规模这两年变化大不大、机构持有比例多不多；
股票仓位多少、管理费/托管费/销售服务费三档各是多少（注明份额类别）；
重仓了什么、集中度高不高，有没有结构性风险要提醒我。
```

### P11 持仓名实核对与风格漂移
覆盖：holdings-style（标签核对 / 集中度 / 多报告期漂移 / 持仓法+净值回归 RBSA 双轨）

```text
看看 <基金代码> 的持仓跟它"<消费/医药/科技>"的名头符不符？
最近 <2-4> 个报告期风格有没有漂移？
持仓法和净值回归两条路都跑一下，互相验证，两边结论不一致也要告诉我。
```

### P12 多基金重合度
覆盖：holdings-style Step 3（重合度矩阵 / 共同重仓表）

```text
我想同时配 <基金A> 和 <基金B>，帮我算算这两只重仓股重合度高不高，
会不会看着买了两只、其实等于没分散。
```

### P13 基金经理画像
覆盖：manager-profile（全部产品按任职区间 / 共管标注 / 风格一致性 / 容量与规模变化）

```text
<基金经理姓名> 这个经理靠谱吗？把他管过和正在管的所有产品列个清单，
严格按任职区间算每一段的业绩和同期基准超额，共管的单独标注；
他的风格这几年稳不稳定？规模膨胀之后业绩有没有变化？同名经理注意别搞混人。
```

### P14 持仓基金跟踪预警
覆盖：fund-watch（经理变更公告 / 规模申赎 / 仓位变化 / 风格漂移 / 业绩偏离 / 费率变化 / 只评发现不评基金）

```text
我持有 <基金A> 和 <基金B>，帮我盯一下最近 <一个季度> 有没有变化：
经理换没换（以公告为准）、规模有没有大进大出、单一机构占比高不高、
股票仓位动没动、费率改没改、业绩相对基准和同类有没有持续掉队。
按严重程度列出需要我注意的发现就行，不用给评级和买卖建议。
```
