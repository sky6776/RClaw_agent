# glmocr-formula — Prompt 模板

GLM-OCR 公式专用变体：从图片/PDF 识别数学公式（复杂方程、积分、矩阵、行内/块级公式、
文内混排）并输出 LaTeX。参数与 glmocr 一致（file/file_url 二选一、页范围、保存）。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P95 起），与其他分册不重号。

整理日期：2026-09-05

---

### P95 公式识别转 LaTeX
覆盖：extract_formulas（公式 → LaTeX；首次展示时会问一次"保留原始 LaTeX 还是转 Unicode 可读格式"，之后记住选择）

```text
把这张 <数学卷子/论文截图> 里的公式都识别成 LaTeX，
包括行内公式和独立公式块，结果存成文件。
```
