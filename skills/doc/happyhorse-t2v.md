# happyhorse-t2v — Prompt 模板

阿里云百炼 HappyHorse-1.1-T2V 文生视频：从文本提示词生成物理真实、运动流畅的 MP4
视频（3-15 秒），支持分辨率（480P/720P/1080P）、9 种画幅比例、时长、水印开关与固定种子。
结果链接 24 小时有效，主交付物是本地 MP4 文件。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P128 起），与其他分册不重号。
- API Key 在 `skills/happyhorse_key.toml`（t2v/i2v/r2v 系列共享），只由脚本内部读取，
  不打印不外传；各 skill 的 config.toml 只存模型与请求参数。
- 按秒计费（480P 0.45 / 720P 0.9 / 1080P 1.2 元/秒），生成前 agent 先与用户确认分辨率
  与时长；单次生成通常 1-5 分钟，期间耐心等待轮询结果。

整理日期：2026-09-22

---

### P128 基础文生视频
覆盖：generate_video（prompt + save 必填；其余参数走 config 默认值 480P / 16:9 / 5 秒 / 不加水印）

```text
帮我生成一段视频：<画面描述，写清主体、动作、场景与镜头运动>，
保存到 output/<文件名>.mp4。
```

### P129 横屏高清长镜头
覆盖：resolution + ratio + duration 覆盖默认值；生成前确认费用

```text
生成一条 <1080P> 的 <21:9> 宽幅视频，时长 <10> 秒：<无人机镜头缓缓拉升，
<场景描述>>，保存到 output/<文件名>.mp4。生成前先按
<1080P> 1.2 元/秒算一下这段的费用并跟我确认。
```

### P130 竖屏短视频
覆盖：9:16 竖屏 + 720P 画质（适合朋友圈/手机端分发的常见组合）

```text
做一条 <9:16> 竖屏短视频：<描述>，<720P> 画质、<5> 秒，
存到 output/<文件名>.mp4。
```

### P131 固定种子与水印
覆盖：seed（可复现生成）+ watermark 水印开关；分辨率/时长沿用上次参数

```text
用固定种子 <42> 重新生成这条视频：<原提示词>，
分辨率、画幅、时长都不变，这次加上 <右下角水印>，保存为 output/<文件名>-b.mp4。
```

# 功能点覆盖对照表

| 功能点 | 覆盖的 prompt |
|---|---|
| prompt + save 基础文生视频 | P128 |
| resolution 分辨率档位与计费确认 | P129 |
| ratio 画幅（16:9 横屏 / 9:16 竖屏等 9 种） | P129、P130 |
| duration 时长（3-15 秒） | P129、P130 |
| seed 固定种子可复现 | P131 |
| watermark 水印开关 | P131 |
| 共享 happyhorse_key.toml，Key 不打印不外传 | 内置约束，验收时检查输出 |
| video_url 24 小时有效，交付以本地 MP4 为准 | 内置约束 |
