# 持仓跟踪 watch-positions — Prompt 模板

覆盖本包 6 个子技能：watchlist / intraday-watch / close-recap / event-monitor，
以及两个产出技能 report-render（PDF/DOCX）、xlsx-author（Excel）和 cron 定时调度。

- 占位符用 `<>` 标出，替换后即可使用。
- Prompt 不需要指定数据轨（MCP 双轨 / akshare 兜底脚本），技能按配置自动选择；
  若要专门测兜底轨，可在任意一条后追加：「假设 MCP 不可用，走兜底脚本」。
- 溯源纪律（`[披露]/[测算]/[推断]/[媒体]` 标签、`[n]` 引注、`覆盖范围与局限` 区块）是
  内置行为，不写进 prompt；验收时检查输出里是否带了即可。
- 编号沿用全集 P1–P26，与其他包分册不重号。跨包组合见
  `cross-package.md`（P25/P26 也用到本包功能）。

### P1 自选清单管理
覆盖：watchlist（创建 / 加标的 / 移除 / 查看 / 重命名 / 权重成本写入 / 名称→代码解析）

```text
帮我建一个名叫"<清单名>"的监控清单，把<公司简称1>、<公司简称2>、<港股简称>、<美股简称>都加进去；
其中<公司简称1>是我的重仓，仓位 <x>%、成本 <y> 元/股，<公司简称2> 仓位 <x>%；
然后看看我现有的"<旧清单名>"里都有什么；
把"<旧清单名>"改名叫"<新清单名>"；再把<要移除的票>从里面去掉。
```

### P2 盘中快照
覆盖：intraday-watch（实时报价 / 相对基准 / 超出自身常态波动的异动 / 数据时点标注）

```text
现在盘中什么情况？看一下"<清单名>"，和<基准指数>比哪些强哪些弱？
哪些票的波动超出了它们自己的正常范围？不用解释原因，列出值得看的就行。
```

### P3 盘后复盘
覆盖：close-recap（涨跌明细 / 异动归因（披露事件优先）/ 大盘板块背景 / 明日日历 / 自定义区间 / 组合收益）

```text
今天收盘了，复盘一下"<清单名>"：哪些票动了、为什么动（有公告的查公告，别瞎编），
需要我关注或决策的是什么，明天有哪些日子要注意？
另外算一下这个加权组合今天的整体收益，谁贡献最大谁拖累最大。
顺便也看看自 <某个日期> 以来累计的表现。
```

### P4 事件监控
覆盖：event-monitor（公告/业绩预告/解禁/质押/增减持扫描 / 🔴🟡⚪分级 / 零事件报告）

```text
把"<清单名>"里的票扫一遍风险事件：公告、业绩预告、限售解禁、股权质押、大股东增减持，
窗口从上次扫描之后算起，按严重程度排好序告诉我，哪些需要立刻看、哪些记下来跟踪就行。
```

### P5 定时自动化
覆盖：event-monitor Step 5 + cron 调度

```text
以后每个交易日收盘后 <15:30> 自动帮我跑一遍"<清单名>"的盘后复盘和事件监控，
每周一早上再额外跑一次全量事件扫描。确认一下你配置的节奏。
```

### P6 导出 Excel
覆盖：xlsx-author（Class B 筛选/快照簿，`来源` 工作表 + `来源编号` 列）

```text
把刚才的<盘中快照/事件监控/复盘归因表>整理成一个 Excel 发我，我自己还要再筛，
每行数据带上来源编号，来源和口径单独放一张表。
```

### P7 导出 PDF / Word 报告
覆盖：report-render（PDF 供传阅 / DOCX 供编辑）

```text
把今天的复盘写成一份正式的 PDF 复盘报告，我要转发给同事看。
```

```text
把这份复盘导出成 Word 版，我要在上面批注修改。
```

> 同一功能两种问法：要"读"给 PDF，要"改"给 Word——可以各测一次。
