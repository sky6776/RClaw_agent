# glmocr-handwriting — Prompt 模板

GLM-OCR 手写体专用变体：识别图片/PDF 中的手写文字（草书/印刷体、中英文、手写+印刷混排、
手写公式与批注），转成可编辑文本。参数与 glmocr 一致。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P96 起），与其他分册不重号。

整理日期：2026-09-05

---

### P96 手写笔记转文字
覆盖：extract_handwriting（手写/混排内容 → 可编辑文本 Markdown；完整展示、保存告知路径）

```text
识别这份手写笔记 <图片路径>，转成可编辑的文字，
里面手写和打印混排的部分也要分开整理对，结果存成文件。
```
