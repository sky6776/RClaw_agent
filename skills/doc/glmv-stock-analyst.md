# glmv-stock-analyst — Prompt 模板

股票分析与走势预测（港股/A股/美股）：web_search 确认代码 → 采集 K 线/资金流等数据 →
补齐新闻与证据 → GLM-5V 看图生成图文结合的结构化报告（三维结论 + 目标价 + DCF 估值 + 来源登记）。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P47 起），与其他分册不重号。
- 简单查询类（「XX 现在多少钱」「XX 代码是什么」）不会触发完整分析流程，走轻量搜索（见 P53）。

整理日期：2026-09-05

---

### P47 个股深度分析
覆盖：完整流程（确认代码 → 采数据/图表 → 补新闻/一致预期/资金流 → 看图出报告：技术面、商业模式、财务预测、估值 DCF、三情景目标价、多空对比、翻转条件、风险提示）

```text
分析一下 <腾讯>（0700.HK）最近走势怎么样，能不能买？
给我一份图文分析报告：技术面、基本面、估值都要有，
结论给清楚观点、建议、风险等级和目标价。
```

### P48 多股对比
覆盖：追问分支「比较 XX 和 YY」（各自完整分析后对比）

```text
比较一下 <贵州茅台> 和 <五粮液>，哪只更值得配置？
各自分析完给我一个对比结论。
```

### P49 场景假设分析
覆盖：追问分支场景分析（基于已有数据做情景推演）

```text
如果明天 <低开 3%> 怎么办？基于刚才的分析给我一个应对预案，
支撑位和止损位分别是多少。
```

### P50 最新消息
覆盖：追问分支「XX 最新消息」（只搜新闻、精炼回复，不重跑全流程）

```text
<腾讯> 最近有什么最新消息吗？
```

### P51 业绩演示材料提取
覆盖：fetch_ir（HTTPS PDF 业绩材料 → 提取图表进报告，最多 50 页，dpi 36–600）

```text
把 <公司名> 最新业绩发布材料的 PDF 图表也提取出来，纳入分析报告。
```

### P52 报告导出 PDF/DOCX
覆盖：export_report（format: pdf / docx / both，仅用户明确要求时）

```text
把刚才的 <股票> 分析报告导出成 PDF 发我。
```

### P53 简单行情查询（不触发完整分析）
覆盖：简单查询分支（web_search 带当日日期词、核对页面时间戳、标注数据时点、不把昨收当最新）

```text
腾讯现在的股价是多少？
```
