# seedream-image — Prompt 模板

火山方舟 Doubao Seedream 5.0 lite 图片生成/编辑:文生图、图生图编辑(增/删/替换/修改)、
视觉信号控制(涂鸦/线框标记)、多图融合(2-14 张参考图)、参考图生图(保持人物/风格/款式)、
组图输出(分镜/成套视觉/壁纸)、联网搜索时效内容。

- 占位符用 `<>` 标出,替换后即可使用。
- 编号为全集连续编号(P148 起),与其他分册不重号。
- API Key 在 `skills/ark_key.toml`([ark].api_key,火山方舟系列共用),只由脚本内部读取;
  请求参数走 `skills/seedream-image/config.toml` 的 `[seedream]` 表(默认 2K / png / 不加水印)。
- 提示词建议 ≤300 汉字,要渲染的文字放双引号;参考图 ≤14 张(单张 ≤30MB),
  组图模式参考图 + 生成数 ≤15;单张 2K 约 10-30 秒,4K 组图可达数分钟。
- 结果中的 url 仅 24 小时有效,主交付物是本地图片文件。
- 不覆盖 Seedream 5.0 pro/flash 专属能力(交互编辑/图层拆分/透明背景/fast 优化),
  用户需要时如实告知,不要伪造参数。

整理日期:2026-09-23

### P148 文生图(指定档位与画幅)
覆盖:generate_image(prompt + save 必填;size 档位 2K/3K/4K;比例写进提示词)

```text
生成一张 <描述> 的图,<竖版/16:9> 构图、<4K> 档位,保存到 output/portrait.png。
```

### P149 图生图编辑(增 / 删 / 替换 / 修改)
覆盖:image 单图 + 编辑指令;指名对象、避免代词、声明保持不变项

```text
编辑图片 <media/in.png>:<把图中女生的帽子去掉>,其余保持不变,保存到 output/edited.png。
```

```text
编辑图片 <media/robots.png>:<让图中最高的那只机器人变成透明水晶材质>,
保持 <位置和姿势> 不变,保存到 output/crystal.png。
```

### P150 视觉信号控制(涂鸦 / 线框标记)
覆盖:用户在输入图上涂鸦/画框/箭头标记,提示词引用标记颜色与位置

```text
参考 <media/marked.png> 上的标记:<红色涂抹位置放入电视,蓝色涂抹位置放入沙发>,
不改其他布局,风格与整张图 <原木风> 一致,保存到 output/room.png。
```

### P151 多图融合 / 复合编辑
覆盖:image 2-14 张;替换/组合/迁移三类模板,逐图写明用途

```text
把 <media/person.png> 图一人物的服装换成 <media/outfit.png> 图二的服装,
保持 <动作和表情> 不变,保存到 output/fusion.png。
```

### P152 参考图生图(保持形象 / 风格 / 款式)
覆盖:提示词两部分——先指明参考对象,再描述生成画面

```text
参考 <media/character.png> 中的人物形象,做一个 <动漫手办> 放在桌上,背景放一个
印有角色图像的生日礼物盒,室内场景,尽可能真实,保存到 output/figure.png。
```

### P153 组图输出
覆盖:max_images 开启组图(自动加 _001.._NNN 序号);「一套/一组/N 张」触发,逐张描述差异

```text
生成一组 <4> 张电影级科幻分镜:场景1 <宇航员在空间站维修飞船,中全景>;场景2 <陨石带袭击,
广角史诗镜头>;场景3 <紧急躲避,近景动态>;场景4 <逃回飞船,舱内暖光>,保存到 output/storyboard.png。
```

### P154 联网搜索时效内容
覆盖:web_search=true(天气预报、时事海报等需最新信息的图)

```text
生成一张 <上海未来 5 日天气预报图>,现代扁平化插画风格,横向排版 <5> 个等宽卡片,
联网查询最新天气数据,保存到 output/weather.png。
```
