# happyhorse-i2v — Prompt 模板

阿里云百炼 HappyHorse-1.1-I2V 图生视频：以一张首帧图片为起点生成物理真实、运动流畅的
MP4 视频（3-15 秒），支持公网图片 URL 或本地图片（自动 base64 上传）。输出画幅自动跟随
首帧图片，不支持 ratio 参数。结果链接 24 小时有效，主交付物是本地 MP4 文件。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P132 起），与其他分册不重号。
- API Key 在 `skills/happyhorse_key.toml`（t2v/i2v/r2v 系列共享），只由脚本内部读取，
  不打印不外传；各 skill 的 config.toml 只存模型与请求参数。
- 按秒计费（480P 0.45 / 720P 0.9 / 1080P 1.2 元/秒），生成前 agent 先与用户确认分辨率
  与时长；单次生成通常 1-5 分钟，期间耐心等待轮询结果。
- 首帧图片要求：jpg/jpeg/png/webp，宽高 ≥300 像素，宽高比 1:2.5 至 2.5:1，≤20MB。

整理日期：2026-09-22

### P132 基础图生视频
覆盖：generate_video（image URL + prompt + save 必填组合；其余参数走 config 默认值 480P / 5 秒 / 不加水印）

```text
让这张图动起来：<图片URL>，画面里 <动作描述，如云缓慢飘过、灯光逐一点亮>，
保存到 output/<文件名>.mp4。
```

### P133 本地照片变视频
覆盖：image 传 workspace 本地路径（脚本自动转 base64 上传）

```text
把 <input/照片.png> 变成一段短视频：照片里的人物 <微笑转头/头发随风轻扬>，
镜头 <缓缓推近>，保存到 output/<文件名>.mp4。
```

### P134 指定分辨率与时长
覆盖：resolution + duration 覆盖默认值；生成前确认费用

```text
用 <input/海报.png> 做一段 <1080P>、<10> 秒的视频：海报文字逐行亮起，
光效从左到右扫过，保存到 output/<文件名>.mp4。生成前先按
<1080P> 1.2 元/秒算一下这段的费用并跟我确认。
```

### P135 固定种子与水印
覆盖：seed（可复现生成）+ watermark 水印开关；分辨率/时长沿用上次参数

```text
用固定种子 <42> 重新生成刚才那条视频：<同一张图 + 同一段动作描述>，
分辨率和时长都不变，这次加上 <右下角水印>，保存为 output/<文件名>-b.mp4。
```
