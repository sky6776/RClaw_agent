# glm-image-gen — Prompt 模板

智谱 GLM-Image 文生图：从文本提示词生成图片并下载到本地，支持多种宽高比、HD 高清、
水印开关。生成链接有效期 30 天，主交付物是本地文件。

- 占位符用 `<>` 标出，替换后即可使用。
- 编号为全集连续编号（P104 起），与其他分册不重号。
- 尺寸/质量/水印是共享配置项（`[glm_image]`），对话中指定后由 agent 调整配置生效。

整理日期：2026-09-05

---

### P104 文生图（指定比例与画质）
覆盖：generate_image（prompt ≤1000 字 + save 保存路径必填；对话中指定尺寸/比例/水印 → 调整配置）

```text
生成一张 <描述> 的图，<16:9> 比例、高清、不要水印，
保存到 output/ 目录。
```

### P105 批量多主题生成
覆盖：多主题批量（多条 jsonl 逐条生成）+ user_id 内容审核标识

```text
帮我生成 <3> 张不同主题的海报：<主题1>、<主题2>、<主题3>，
风格统一，都存到 output/ 下。
```
