# 字段清洗规则（xianyu-scrape）

首次清洗数据前通读一遍。

## URL 模式速查

| 用途 | URL |
|---|---|
| 搜索 | `https://www.goofish.com/search?q=<关键词>` |
| 商品详情 | `https://www.goofish.com/item?id=<商品id>` |
| 卖家主页 | `https://www.goofish.com/personal`（详情页 `a[href*="/personal"]` 即卖家入口） |

- 落地形态以最终 URL 为准（可能带 tracking 参数）；判定成败看页面内容，不苛求 URL 形态。
- 翻页：把已有 `page` 参数就地替换为新值，没有才追加；翻页后 id 集合与上页完全相同 = 到底或不支持，如实收尾。
- 商品 id 提取：`[?&]id=(\d+)`（带参数边界，防咬到 tracking 参数）。

## 三堵墙特征

| 墙 | 特征 |
|---|---|
| 风控/验证 | 主机名或路径含 `captcha`、`punish`（查询参数不参与判定）；滑块/点选验证码组件 |
| 登录墙 | 硬重定向到登录域或阻断式登录浮层（扫码/短信），商品不可提取；角落「请登录」入口不算墙 |
| 空结果 | 「没有找到相关宝贝」类文案 |

## 数值清洗

1. **价格**：识别 `¥`/`￥` 前缀或独立数字；剔除数字与 `.` 以外字符转浮点。闲鱼常见整数价（`299`），小数保留原样（`99.90` 不写成 `99`）。区间价取下限并标注「区间价」。
2. **想要人数**：`X.X万人想要` → `X × 10000` 取整；`88人想要` → `88`；缺失留空。`想要文本` 保留原文。
3. **数量类换整数，价格保留小数**——与 CSV 可排序、价格精度两项要求一致。

## CSV 输出约定

- 表头（最小集在前）：`商品标题,当前价格(元),想要文本,想要人数,商品链接,采集时间`
- 扩展列参考：`卖家名称,成色标签,地区,描述摘要`
- **防公式注入**：标题/卖家/描述等页面文本字段以 `=`、`+`、`-`、`@` 开头时，写入前在最前面加单引号 `'`。
- 文件 UTF-8；尽量以 BOM（U+FEFF）开头。BOM 写入与否无法回读目检——没把握标「BOM 未确认」，不得声称「含 BOM」。
- `采集时间` 格式 `YYYY-MM-DD HH:MM`，同任务所有行同一时间戳。

## 常见失败形态

| 形态 | 识别 | 处置 |
|---|---|---|
| 未登录搜索被弹层拦截 | 结果区空白 + 登录浮层 | 走登录协作，登录后重新搜索 |
| 链接截断切进 id | 链接顶满 150 字符且数字贴末尾 | 找同商品完整链接；找不到丢条标注 |
| 求购帖混入结果 | 标题含「求购」「收」 | 正常商品保留；用户明确排除时按标题关键词过滤（排除词在报告列出） |
| page 参数无效 | 翻页后 id 集合与上页相同 | 如实报告已采集数收尾 |
| 价格为「面议」等非数字 | 价格文本无数字 | 价格留空，文本进「价格文本」备注，不猜数 |
