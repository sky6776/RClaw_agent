# 图形界面（桌面版与安卓 APK）

[← 返回 README](../README.md)

桌面版与安卓 APK 共用同一个 React + Vite + Tailwind 前端（`crates/rclaw-desktop/ui/`），宿主为 Tauri 2。图形壳对运行时而言是一个名为 `desktop` 的虚拟通道：窗口输入写入消息总线，出站消息经 Tauri 事件推给 Webview；安全语义与 CLI 一致——模型流式片段在完成闸门通过前不外发。构建与安装见 [平台与构建](platforms.md)。

## 导航

- **桌面侧栏**（自上而下）：对话 → 会话 → 智能体 → 工具 → 技能 → 工作区 → Agent → 自进化 → 定时任务 → 配置 → 关于。
- **安卓抽屉**：在 Agent 之后增加「任务概览」，配置之后增加「主题」；顶部另有「浏览器」入口。
- 侧栏的 Agent / 任务概览项带实时徽标，显示运行中的子代理 / 任务数。

## 对话

- 发送 / 停止、附件、引用、复制、多选导出；会话新建、重命名、归档、恢复、永久删除。
- **⑂ 分叉**：消息下方按钮（移动端长按菜单「从这里分叉到新会话」）从该用户消息复制出新会话分支，并把锚点之后的文件改动回滚到该时刻，原会话不动。语义见 [长程会话](context-management.md#fork-会话分叉)。
- **排队消息**：agent 运行期间输入的消息进入队列，空闲后逐条发送；每条可「编辑」（移出队列回填输入框）、「删除」、或「立即」绕过忙碌状态投递为当前 turn 的插话。
- **计划与工作流卡片**：`PlanRun` 多步计划以可折叠的步骤卡片展示，可在波次边界暂停 / 继续；会话页显示最近计划的 todo 列表；工作流有独立卡片（WorkflowCard）。
- **思考块**：显示持续时长，可单个 / 全部折叠。
- **工具调用行**（ToolCallRow）：实时显示工具 / Skill 名、状态、耗时；展开可看参数、输出、读到的文件内容、shell 命令、写 / 删前快照与新旧 diff。
- **轮次导航**（RoundNav）：桌面为左侧 rail，移动端为轮次计数按钮 + 底部列表。
- **媒体**：消息内图片 / 视频 / 文档预览；会话画廊按消息顺序左右滑；图片 1–8× 缩放、平移、查看原图；视频应用内流式播放（本机带随机 token 的 Range HTTP 服务）；照片编辑支持旋转、画笔、撤销、保存或发送。
- **安卓附件菜单**：拍照、拍视频、录音；录音可作为附件发送，或经本地 whisper 转文字回填到草稿。
- 斜杠命令（`/llmodel`、`/context`、`/cancel` 等）直接在输入框输入，与 CLI 一致。

## 智能体（Bots）

新建 / 编辑 / 删除持久身份 bot：人格（persona）、职责描述、固定 provider、禁用工具列表；一键打开 bot 的专属会话（`desktop/bot-<name>`）。选择 2–6 个 bot 建群聊房间：查看转录与活动流、@点名成员、发送任务、取消编排、删除群。语义见 [多智能体协作](multi-agent.md#bot-与群聊)。

## 工具

搜索并逐项启停内置 / MCP 工具，偏好跨重启保留。禁用后立即禁止执行，并从下一 turn 的工具描述中移除。

## 技能

搜索技能，启用 / 禁用（禁用 = 归档到 `skills/.archive/`）。技能页没有安装或编辑入口：技能内容由 agent 经 `skill_manage` 维护，`SKILL.md` 等文本可在「工作区」页直接编辑，或直接改数据目录 `agent/skills/`。配置页中的 **SkillOpsCard**（仅安卓 APK 显示，桌面接口不可用时整卡隐藏）负责脚本哈希审批 / 撤销，以及 `agent/skills/*/*.toml` 与顶层 `agent/skills/*.toml`（`ark_key.toml` 等 Key 文件）的编辑。

## 工作区

- 面包屑文件树，新建文件 / 文件夹，文本编辑，复制、重命名、删除；安卓支持剪贴板导入、保存到本地、转发。
- 根部的虚拟 `rclaw.toml` 与「配置」页指向同一实体：保存前校验 TOML 语法与 provider 字段。

## Agent

实时显示后台 / 并行子代理：状态（排队 / 运行 / 等待 / 取消中 / 成功 / 失败 / 已取消）、当前阶段、步数、排队 / 运行时长、累计 token。点进卡片进入详情：

- 实时头部（状态 / 时长 / token / 模型调用数）；
- 完整活动记录——思考块、正文、工具与 Skill 调用及其详细入参出参、状态时间线、handoff / 错误；
- 向运行中的子代理发消息（在其推理前后的安全点读取）、取消执行；
- 返回键回到列表并恢复到原卡片位置。

「清除历史」只删除已结束执行及其活动记录，不动用户会话与活跃任务。这里登记的是 `Agent` / `Task` 子代理与工作流 ask；`PlanRun` 步骤的进度看对话页的计划卡片。实现见 [多智能体协作](multi-agent.md#执行登记与实时进度)。

## 任务概览 / 任务

桌面 TaskPanel 显示任务状态统计、当前会话上下文窗口占用与进程内存占用；移动端 TaskOverviewPanel 是独立页面。两处都能点进任务看实时详情、清理已结束记录。

## 自进化

展示自动记忆 / 自进化 / 策展器 / 会话压缩四个开关状态，近 14 天活跃度，工具 / 技能使用 Top 8，会话与消息数，记忆占用，最近 8 次技能变更，以及 `MEMORY.md` / `USER.md` 正文（各最多 24000 字符）。面板只有「刷新」操作；开关在 `rclaw.toml` 的 `[agent]` 段修改。语义见 [记忆与自进化](self-evolution.md)。

## 定时任务

查看、刷新、删除定时任务。新增通过对话让 agent 调用 `cron_add`。见 [定时任务](cron.md)。

## 配置

- 可视化编辑 `rclaw.toml`：保存前做完整校验（TOML 语法、provider 字段）；每 3 秒回读磁盘，与工作区中的虚拟 `rclaw.toml` 双向同步。
- **工具权限模式**：「默认权限（推荐）」——文件工具限制在 `agent/` 工作区内，越界弹窗确认（120 秒无应答按拒绝），shell 只限制工作目录；「完全访问」（`permission_mode = "full"`）——窗口消息被提升为 `Unrestricted` 权限。请谨慎使用，见 [安全设计](security.md)。
- **界面标语**：标题栏循环显示的自定义文案。
- SkillOpsCard（仅安卓，见上文「技能」）。

## 主题 / 窗口

- 主题选择器提供 6 套预设（深邃夜色 / 简约日间 / 浪漫星空 / 森林之夜 / 樱花粉 / 奶油暖阳），安卓在抽屉「主题」项、桌面在标题栏按钮打开。
- 桌面标题栏：拖动（双击最大化）、任务面板开关、主题选择、浏览器窗口开关、最小化 / 最大化 / 关闭（关闭 = 隐藏到托盘）。
- 安卓手势：边缘滑动开关抽屉、系统返回键按弹层栈逐级返回、长按呼出菜单。

## 关于

显示各 crate / WebView / Rust / 提交版本；GitHub Release 应用内更新（安卓端安装前经 `verifyUpdateApk` 预检包名、签名与 versionCode）；安卓保活引导卡片（KeepAliveCard）。

## 浏览器

与 agent 的 `browser_*` 工具共用同一个浏览器会话，供用户手动上网或人工过验证码：

- **安卓**：抽屉顶部「浏览器」入口打开应用内浏览面板（长驻调试 WebView），有地址栏（URL / 搜索词）、前进 / 后退 / 刷新、全屏切换、收起 / 关闭；系统返回键 = 网页后退。
- **桌面**：标题栏地球按钮把无头浏览器切为可见的真实浏览器窗口（Chrome / Chromium / Edge，可用环境变量 `RCLAW_BROWSER_EXE` 指定可执行文件），用户可像普通浏览器一样操作，再次点击切回无头。

工具语义见 [内置工具](tools.md#浏览器)。

## 桌面宿主

| 模块 | 职责 |
|---|---|
| `home.rs` | 数据目录解析：`RCLAW_HOME` > `%USERPROFILE%\.rclaw` > XDG > `~/.config`；旧 `%APPDATA%\rclaw` 一次性迁移 |
| `wizard.rs` | 首运行 `rclaw.toml` 生成（固定字段集；provider 名白名单字符，API Key / 模型名拒绝引号、反斜杠与控制字符，防 TOML 注入；原子写入，拒绝覆盖已有文件） |
| `agent.rs` | 装配 AgentLoop、Cron、Heartbeat、BotRouter、工具权限与浏览器；出站 → Tauri 事件桥 |
| `permissions.rs` | 工作区外访问的授权弹窗（120 秒无应答按拒绝），授权按（操作, 落点）缓存 |
| `groups.rs` | bot 群聊的有界编排（轮次 / 消息数上限、@点名） |
| `commands.rs` | Tauri 命令层：会话、计划 / 工作流、Agent、工具 / 技能、配置、工作区、媒体、更新、窗口、bot / 群聊、采集 |
| `export.rs` | 会话导出：Markdown、内嵌图片的 DOCX、自包含 HTML |
| `media_stream.rs` | 本机媒体服务：带随机 token 的 Range HTTP，供视频 / 音频应用内流式播放（图片走 base64 / 预览命令） |
| `tool_events.rs` / `exec_events.rs` | 保序桥接工具调用事件 / 子代理实时事件到前端 |
| `insights.rs` | 聚合会话 / 技能 / 记忆统计供自进化面板 |
| `keep_alive.rs` / `android_status.rs` / `android_host.rs` | 安卓保活、通知与任务状态桥接、JNI 导出面 |

托盘常驻：关闭窗口仅隐藏，托盘菜单提供「显示 RClaw / 退出」。

## 安卓宿主

- **NativeBridge**（Java）：更新校验与安装、系统 / 应用内浏览器、媒体打开与分享、剪贴板、拍照 / 录像 / 录音、相册与下载目录保存、whisper 转写、通知、保活、原生生命周期回调。
- **浏览器**：长驻调试 WebView + 抽象 socket 的 CDP 会话；应用内浏览面板可人工过码；离屏截图走 `View.draw`，可见时走 CDP。
- **保活**：前台服务、开机接收器、AlarmManager 看门狗维持无头运行；健康检查、退避恢复、按需 wake lock、任务状态与完成通知。
- **Python**：Chaquopy Python 3.12 进程内执行技能脚本，严格串行、超时协作中断、脚本哈希审批（配置页 SkillOpsCard）。
- **gbrain**：进程内注册，不启动 MCP 子进程；数据归一化到应用私有 `files/gbrain`。见 [gbrain 知识库](gbrain.md)。
- **技能**：首次启动按 APK 版本解包内置技能，保留用户改动；技能配置文件位于 `no_backup` 目录。
- **语音**：whisper `.so` 与 `ggml-base-q5_1.bin` 模型可内置，录音 / 上传音频本地转写。
- **数据目录**：Agent 根归一到私有 `filesDir/agent`，旧 `filesDir/rclaw` 可迁移。
- 工程结构：arm64、minSdk 26 / targetSdk 36，含 Tauri 生成层、Java / Kotlin 宿主、Python 桥、JNI 库、模型资产、FileProvider、分享接收与相机 / 录音桥。
